# 單機版採購連接工具（0.6.0）

適用 Chrome / Edge 桌面版。只接受 `http://127.0.0.1:3210/purchase` 發出的採購要求；`/purchase/setup` 只能檢查工具連線。其他埠、其他網域與線上版不能發出要求。單機程式若設定其他 PORT，採購橋接功能不會啟用。

## 使用者安裝後設定帳號

1. 完整解壓縮單機版，啟動 Start.cmd。
2. 在 Chrome 開啟 `chrome://extensions`，或 Edge 開啟 `edge://extensions`。
3. 開啟開發人員模式，選「載入未封裝項目」，指定此 browser-extension 資料夾。
4. 在同一瀏覽器設定檔開啟 http://127.0.0.1:3210/purchase/setup ，按頁面說明自行登入藥典及高一。
5. 帳密只在中盤官方登入頁輸入。本工具不提供帳密欄位、不保存密碼、不匯出 Cookie，也沒有預設藥局帳號。可由使用者自行選擇瀏覽器密碼管理員記住密碼。
6. 保留兩家中盤分頁。更新工具或登入後，重新整理中盤及單機採購頁，再檢查連線。

商品查價、購物車金額同步及加入購物車需要網路。斷網仍能使用藥品地圖、消耗盤點及手動採購草稿。加入購物車前工具會重新核對商品與價格；回應不明時先手動核對，不要直接重試。最終訂單由使用者在中盤網站確認，本工具不會結帳。

藥典網址為 http://www.yudan.com.tw/yudan_web_wt/ ，高一網址為 https://www.gaoipharma.com.tw/ 。藥典目前使用 HTTP。請在官方網站自行輸入帳密與驗證碼，登入逾期後亦在官方網站重新登入。

打包時僅包含 manifest.json、background.js、bridge.js、supplier.js 及本說明，不包含瀏覽器設定檔、登入資料、環境變數或使用者資料。
